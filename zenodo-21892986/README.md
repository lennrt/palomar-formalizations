# Polynomial-Delay Enumeration of Fixed-Endpoint Vertex-Regular Paths

DOI: [10.5281/zenodo.21892986](https://doi.org/10.5281/zenodo.21892986)

- `preprint.pdf` is the deposited preprint.
- `palomar/` is the independent Lean project prepared for Palomar submission.

The Palomar entry is deliberately narrower than the paper: it certifies the
vertex-splitting regularity model, the exact alternating-walk lift, and the
prefix-deletion/reachability join. It does not claim to formalize the
enumerator, the Goldberg--Karzanov implementation, simple-path bookkeeping,
or the polynomial-delay analysis. The Challenge imports CSLib, which Palomar
accepts as a qualified trust surface and displays with a warning.
