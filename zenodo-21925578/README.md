# Exact Spectra of Generalized Cubic Subdivision Matrices

DOI: [10.5281/zenodo.21925578](https://doi.org/10.5281/zenodo.21925578)

- `preprint.pdf` is the deposited preprint.
- `palomar/` is the independent Lean project prepared for Palomar submission.

The Palomar entry advertises the exact scalar certificates proved in Lean:
the zero-mode factorization, a real-root exclusion lemma, the complex
double-ring outer-symbol factorization, and the one-dimensional double-ring
factorization. It does not advertise a fully formalized all-valence matrix
spectrum, Fourier decomposition, source-to-matrix reconstruction,
subdominance theorem, or tensor-product interpretation.
