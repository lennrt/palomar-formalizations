# Simpler Graph Conditions for Embedding Tetrahedral Meshes

- DOI: <https://doi.org/10.5281/zenodo.21925574>
- Author: Lennart Rudolph
- Preprint: `preprint.pdf`
- Palomar project: `palomar/`

The Palomar project exposes the abstract safe-cockade induction and the
composition showing how the stated rigidity, separator, minor, and
linkless-embedding inputs make the separate `K_(3,3,1)` exclusion redundant.
Those deep external inputs and the native finite local certificate are not part
of the compared proof cone.
