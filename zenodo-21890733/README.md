# A Counterexample to Prescribed-Cycle Recovery in Barnette Graphs

- DOI: <https://doi.org/10.5281/zenodo.21890733>
- Author: Lennart Rudolph
- Preprint: `preprint.pdf`
- Palomar project: `palomar/`

The Palomar project exposes the finite matching-versus-color obstruction and
the abstract forced-edge implication. It does not claim that the Lean code
formalizes the planar embedding, the full coloring construction, or the
external algorithmic Property 1 used by the paper.
